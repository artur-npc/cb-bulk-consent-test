Test Scenarios (EUD-5533)

Scenario 1 — Decline All SHOULD PROPAGATE (Fixed)
1. Accept All on Site 1
2. Go to Site 2 → verify consent was transferred
3. Come back to Site 1 → click "Deny" / Decline All
4. Go to Site 2 → consent must now show as declined
Bug before fix: Site 2 showed "Consent not registered"
Scenario 2 — Remove Preferences (keep Stats + Marketing) SHOULD PROPAGATE (Fixed)
1. Accept All (Preferences + Statistics + Marketing) on Site 1
2. Go to Site 2 → verify consent was transferred
3. Come back to Site 1 → uncheck Preferences only, save
4. Go to Site 2 → consent must reflect the change
Bug before fix: Site 2 showed wrong/stale consent state
Scenario 3 — Remove Statistics only (keep Preferences + Marketing) SHOULD NOT PROPAGATE (By design)
1. Accept All (including Preferences) on Site 1
2. Go to Site 2 → verify consent was transferred
3. Come back to Site 1 → uncheck Statistics only, save
4. Go to Site 2 → consent state must remain unchanged
Scenario 4 — Remove Marketing only (keep Preferences + Statistics) SHOULD NOT PROPAGATE (By design)
1. Accept All (including Preferences) on Site 1
2. Go to Site 2 → verify consent was transferred
3. Come back to Site 1 → uncheck Marketing only, save
4. Go to Site 2 → consent state must remain unchanged
